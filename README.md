# Fashion E-commerce

## Cài đặt

```powershell
cd frontend
npm install

cd ../backend
npm install
```

## Chạy ứng dụng

Mở hai terminal:

```powershell
cd frontend
npm run dev
```

```powershell
cd backend
npm run dev
```

- Frontend: http://localhost:5173
- Backend: http://localhost:3000
- Health check: http://localhost:3000/api/health
